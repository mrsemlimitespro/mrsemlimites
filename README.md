Quero que todo o sistema siga exatamente este estilo:

- Interface Premium

- Dark Mode

- Glassmorphism

- Gradientes Roxo + Azul

- Bordas arredondadas

- Cards modernos

- Sombras suaves

- Glow discreto

- Ícones modernos

- Botões elegantes

- Inputs modernos

- Tipografia limpa

- Espaçamento consistente

- Animações suaves

- Alto desempenho

- Interface extremamente limpa

- Visual tecnológico de alto nível

Todo componente criado futuramente deverá seguir exatamente esta identidade visual.
